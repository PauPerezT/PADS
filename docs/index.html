PADS

Pleasure-Arousal-Dominance analysis from speech. PADS extracts PAD posterior probabilities, optional embeddings, and emotion-octant summaries from audio recordings.

Repository Run the web interface

Install the Python library

pip install git+https://github.com/PauPerezT/PADS.git

After installation, use from pads import extract_features. The trained checkpoints are required for model inference.

Use it in Python

from pads import extract_features

features = extract_features(
    "speech.wav",
    checkpoints_dir="checkpoints/one_sec",
    dimensions=("arousal", "valence", "dominance"),
    outputs=("posteriors", "embeddings", "emotion"),
)

print(features["posteriors"])
print(features["emotion"])

Interfaces

Gradio

Upload or record audio, select PAD dimensions, and export posteriors or embeddings.

pip install git+https://github.com/PauPerezT/PADS.git
pip install gradio
pads-gradio

Emotion tracking

Compare several recordings or inspect how PAD estimates and emotion labels move over time.

pip install git+https://github.com/PauPerezT/PADS.git
pip install gradio
pads-tracking

Streamlit

Interactive waveform, spectrogram, timeline, radar, and emotion distribution views.

pip install -e ".[web]"
streamlit run web/app.py
